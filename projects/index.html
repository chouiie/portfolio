Ocean Pulse — Ocean Health Classification Dashboard

Python · DataHacks 2026 — 3rd Place out of 86 Teams, ML/AI Track

  • Trained a Random Forest Classifier on 286,819 CalCOFI samples achieving 98% accuracy, classifying ocean regions into Healthy, Stressed, or Critical states using phosphate and nitrate as key predictors.
  • Integrated an LLM via REST APIs into a Streamlit dashboard, letting any user input a location to receive ocean health status and region-specific policy recommendations.

Predicting NBA Success from NCAA Performance Metrics

Python · Pandas · Regression Modeling · Statistical Inference

  • Engineered a dataset of 386 drafted players by cleaning and merging 3 sources (61,000+ NCAA records, 13 years of NBA draft data, FiveThirtyEight RAPTOR ratings) with Python and Pandas, resolving entity mismatches.
  • Applied statistical learning theory and linear algebra to build a multiple linear regression (OLS) model predicting NBA impact from college stats, controlling for draft position, position, and age; evaluated features with t-tests, F-tests, and 95% confidence intervals (model F-test p < 0.001).
  • Identified college Box Plus-Minus as the strongest predictor of NBA success (β = 0.40, p < 0.001); eFG% and playing time were not significant; validated assumptions via residual analysis and VIF checks (all VIFs < 2.2).
