Ocean Pulse — Ocean Health Classification Dashboard

Python | DataHacks 2026 — 3rd Place out of 86 Teams, ML/AI Track

  • Trained a Random Forest Classifier on 286,819 CalCOFI samples achieving 98% accuracy, classifying ocean regions into Healthy, Stressed, or Critical states using phosphate and nitrate as key predictors.
  • Built a Streamlit dashboard where any user can input a location to receive ocean health status and AI-powered, region-specific policy recommendations via an integrated LLM.
  • Discovered that 39% of all samples fall in the Critical category and that nutrient levels alone predict oxygen stress before visible signs appear, making 70 years of scientific data accessible to non-specialists.
  • Built with Python, scikit-learn, XGBoost, LightGBM, NumPy, Pandas, Streamlit, REST APIs, Marimo, and Sphinx.
